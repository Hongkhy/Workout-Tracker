# FitTrack

A responsive workout-tracking frontend built with React, TypeScript, and Vite. Explore activity metrics, log workouts, review progress, plan sessions, and track fitness goals using sample data.

## Getting started

Install dependencies and start the development server:

```sh
npm install
npm run dev
```

## Checks

```sh
npm run typecheck
npm run lint
npm run build
```

The app currently uses local sample data; authentication and backend services are not connected.
